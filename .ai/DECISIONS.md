## 决策：投稿审核 fail-closed（唯一路径）

- **状态：** Accepted（已采纳）
- **日期：** 2026-09（项目 README 明确记录）
- **决策：** 所有投稿（单条 / 批量 / 修改）统一走机审编排 `runReview`；AI 审核任何异常（未配置 / 网络失败 / 返回不可解析 / `uncertain`）一律保持 `pending` 转人工，绝不默认放行。
- **理由：** 内容安全优先于发布便利；宁可人工兜底，不可自动放行风险内容。
- **权衡：** 增加人工审核工作量；换来内容安全底线。
- **重新评估的条件：** 若引入可靠的自助审核通道或产品策略明确要求降低人工占比时。

## 决策：用户 / 管理员双 cookie + JWT（jose）认证分离

- **状态：** Accepted（已采纳）
- **日期：** 2026-09（项目 README 明确记录）
- **决策：** 前台用户与后台管理员使用独立 cookie，JWT 内校验 role；写接口第一行校验会话，数据层操作带 `user_id` 归属条件。
- **理由：** 权限边界清晰，防越权；httpOnly cookie 降低 XSS 窃取风险。
- **权衡：** 双 cookie 增加一点复杂度；换来后台与前台权限严格隔离。
- **重新评估的条件：** 引入 OAuth / SSO 等统一身份体系时。

## 决策：SEO 对外域名绝不输出 localhost

- **状态：** Accepted（已采纳）
- **日期：** 2026-09
- **决策：** `site_url` 默认不再为 localhost；sitemap / robots / metadataBase / JSON-LD 统一经 `resolveSiteUrl()` 解析域名（后台 `site_url` → 环境变量 `SITE_URL`），localhost / 127.0.0.1 / 非法值一律视为未配置；未配置时 sitemap 输出空、robots 输出禁止抓取。sitemap / robots 用 `revalidate = 86400` 每日重建缓存。
- **理由：** 防止向搜索引擎输出本机地址污染索引；域名由管理员在后台自定义。
- **权衡：** 未配置域名时 SEO 输出为空（需管理员配置后生效）；换来不会收录 localhost 的错误 URL。
- **重新评估的条件：** 引入按请求 Host 动态生成（会牺牲 revalidate 静态缓存）时。
